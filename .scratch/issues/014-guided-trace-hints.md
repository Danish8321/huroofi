## Decisions (grilling, 2026-10-05)
1. **Stroke data:** Claude drafts the stroke order for all 28 isolated letters in a separate `data/strokes.json`, keyed by letter `index`, with points relative to the font glyph's bounds. Claude renders a review sheet in `docs/review/` and checks it; the maintainer or a teacher signs it off before release. Until then it is marked pending review. The content contract test covers both files.
2. **Completion:** targets are the dots along each stroke; a dot fades once ink lands within the tolerance. Done when every stroke is at least 70% covered, in any order and direction; order and direction are never enforced (no fail state). The start coin of the next unfinished stroke pulses; numbers stay. "I did it!" stays as fallback.
3. **Demo timing:** on entry, after the letter sound, the demo shows every stroke once, in order (~1.5 s each); the first touch on the canvas stops it. After 5 s with no new ink and the trace not done, it shows only the next unfinished stroke, repeating every further 5 s idle. Tapping the helper picture or "Again" replays the full demo.
4. **Modes (Claude, per maintainer: "make it engaging and easy"):** Preschool and Early reader get the full guided trace. Toddler Paint keeps free painting with no check, and gains only the travelling ball once per page, no numbers.
5. **Look (Claude):** the flat 55 % Navy guide is replaced by a pale wide band (the glyph filled light, as `Trace.html`) with a dotted centre path per stroke. Start coins are numbered circles, stroke 1 green, the rest blue (prototype colours), each with a short direction arrow. The demonstrator is a bright ball with a short fading trail, drawn in code (no new art). Dots shrink away when inked; a finished stroke turns its coin into a star. `TraceSpec.textPairs` gets the new dot and coin pairs.
6. **Prototype (Claude):** `Trace.html` already shows coin 1, the dotted path, an arrow and coin 2, so it stays the reference. The plan lists only the deltas (ball, fading dots, star coins, pulsing next coin); no designer file is edited.
