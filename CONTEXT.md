# Huroofi glossary

**Plain form**: Arabic text written without short-vowel marks. Default display.

**Vowelled form**: the same Arabic text with short-vowel marks (ḥarakāt). Shown only in lessons, and only when the parent turns the ḥarakāt toggle on. Every Arabic string a lesson displays has both forms. Each vowelled form is reviewed by a native Arabic speaker before release.

**Ḥarakāt toggle**: the Parent-zone setting that switches lesson text between plain form and vowelled form. Toddler screens always show plain form. Default off.

**Isolated letter**: a single letter shown on its own (big Lesson letter, card letter, chips). It never takes vowel marks, even with the ḥarakāt toggle on.

**Letter shape**: one of four written forms of a letter: alone, start, middle, end. Shown only to Early readers in the Lesson.

**Non-joining letter**: a letter that does not connect to the letter after it (أ د ذ ر ز و). It has only alone and end shapes.

**Picture word**: the Arabic word shown with a letter's illustration (e.g. أسد for أ).

**Parent gate**: the screen that asks a grown-up to press and hold a circle for 3 seconds. Guards the Parent zone and exiting the app.

**Parent lock**: the small lock button on child screens that leads to the Parent gate.

**Child**: the one young learner using this device. The app stores no name, photo or profile for the child, and keeps one set of progress per device. Parent-facing text says "your child".

**Learned letter**: a letter whose lesson the child has completed. Toddler play never makes a letter learned.

**Learning letter**: the one letter the learning path offers next: the first letter, in alphabet order, that is not yet learned within the open stage. None once all 28 are learned.

**Letters to go**: every letter that is neither learned nor the learning letter.

**Daily play time**: the minutes per day the parent allows on child screens (5–60, step 5, default 20). Time on the Parent gate, the Parent zone and the Rest screen does not count. A new day starts at local midnight.

**Rest screen**: the calm screen that replaces any child screen once today's play time is used up. No countdown, no red; only the Parent lock leads anywhere.
