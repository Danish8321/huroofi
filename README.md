# Huroofi handoff pack

1. Unzip this folder where you want the Android project to live.
2. Open the folder in Claude Code (desktop app: open folder; terminal: `cd huroofi-handoff` then `claude`).
3. Ask: "Build this as an Android app in Kotlin with Jetpack Compose, following HANDOFF.md. Start with step 1 and 2 of the build order."

Contents: HANDOFF.md (spec), CLAUDE.md (rules Claude Code reads automatically), data/letters.json, assets/ (cards, illustrations, fonts), design-reference/ (approved screens as HTML and a card overview).
